01　缸尺寸与底部高度

底层梁下离地 = 福马轮安装高度 + 脚轮上方净高。默认 120 + 0 = 120 mm；福马轮高度填 0 表示不安装。

02　各层缸高与操作净空

层号从下往上。中间层净空为缸口到上一层承托框最低横梁下沿；最上层可开放，也可保留封框。

顶部开放时，顶层缸独立使用整个框面；默认 680 × 600 mm，四边最小余量各 7.5 mm。若常规层需要更大外廓，多出的空间会居中分配。

03　四边余量

前后梁放在缸底下方；前后余量应小于对应梁的顶部宽度。

04　型材与层托

默认全 4040、名义壁厚 2.4 mm，对应嘉立创欧标 40 槽 8 的 TXCL-H6-4040。每层承托梁顶面齐平；选择顶部开放时不采购顶部封框型材。

常用名义壁厚可选 1.5 / 1.8 / 2.0 / 2.4 / 2.5 / 3.0 mm；当前嘉立创匹配规格为 2.4 mm。槽型材承载还取决于内部筋位、米重和截面惯性矩。

05　连接方式与立柱对齐

“贯通立柱”保留整根立柱，横梁装在立柱之间；“分段立柱”让上层立柱压在下层框架顶面，立柱按层分段。打孔类方式会在图上显示孔位符号，并自动计入对应加工 / 连接组件。

06　玻璃缸承托与福马轮

承托板和缓冲垫默认都为 0 mm，填 0 表示不放；垫层及玻璃缸底部支撑方式以缸厂家说明为准。福马轮按四角各 1 只绘制。

07　采购定尺与切割损耗

排料按同一规格分别计算。每根原料先扣除两端修整量，再按每个下料件计一次锯缝。

默认 6000 mm 原料、3 mm 锯缝、每端修整 5 mm。嘉立创按单根定制报价时可选择“按成品净长度”。

选中参数可在图上定位。数值仅保留正数、非负数及装配关系等实际约束，不设任意上限；无效组合会暂停下料及费用计算。

05尺寸怎么算

当前按无框平底玻璃龟缸绘制：承托板和缓冲垫按设置值显示；如设置承托板，板件落在前梁、后梁及中间梁上。顶部结构、立柱对齐和节点方式都可切换；福马轮按四角各一只绘制，转接底板已在详细 STEP 中用简化实体表示。背部 X 斜撑及墙面防倾倒件已列入预算，但尚未在 3D 装配体中建模。

参数联动只校验几何与采购长度，不是整架承载验算。打孔类节点的孔径、端距、攻丝和扭矩应按型材厂家连接图确认；4040 应选有明确截面参数的标准型或重型，满水状态禁止推动。
